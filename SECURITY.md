# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

- Use GitHub's private vulnerability reporting: on this repository, open **Security → Report a vulnerability**.
- If that isn't available to you, contact Kol through [kol-ai.app/ai/claude-code](https://kol-ai.app/ai/claude-code) and ask for a private channel.

Include what you saw, the steps to reproduce it, the plugin version (the commit you installed, `claude plugin list`) and your Claude Code version. Please don't include keys, tokens or the contents of `~/.kol`.

We'll acknowledge a report, keep you informed while we work on it, and credit you in the fix notes if you want that.

## Supported versions

The plugin has no release numbers: the latest commit on the default branch is the supported version. Installs follow it after `claude plugin marketplace update kol` and `claude plugin update kol@kol`.
